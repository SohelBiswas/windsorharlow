# Before launch

Four things were on the list. Three are done in the build. One needs network
access I do not have from here, and is one command on your machine.

---

## 1. The contact form — done, with a decision to make later

**The problem:** the form posted to `/api/enquiry`, which does not exist. A
visitor filled it in, and the enquiry went nowhere. Separately, a pill on the
homepage read *"API offline — showing seed content"* to every visitor.

**Now:** there is one switch, `window.WH_API` in `build/shell.py`, currently
`null`. While it is null the site behaves like what it is — a site without a
backend. No failing requests, no status pill, and the form composes the
enquiry and hands it over: a mail link, a copy button, and the message text
itself, so a missing mail client is an inconvenience rather than a loss.

**When you want it to send by itself:** deploy `backend/enquiry-lambda.mjs`
(instructions in `backend/README.md`, about forty minutes, mostly waiting on
AWS), set `WH_API` to its URL, rebuild. The mail handoff stays as the fallback
if a post ever fails.

The form already carries the honeypot field the function checks.

## 2. Accessibility and performance — done

Measured rather than eyeballed: every text/background pair on all 15 pages was
computed against its real painted backdrop, at 1440px and 390px.

**185 contrast failures, from five causes:**

| What | Was | Now |
|---|---|---|
| Pipeline stage names (`Compile`, `Lint`, …) | 1.07:1 — paper on paper-lift, invisible | ink, 15:1 |
| Flipped practice-card headline | 1:1 — ink on ink, invisible | paper, 12:1 |
| Brand blue as text on paper | 4.17:1 | `--violet-ink` #0072BE, 4.61:1 |
| Brand cyan as text on paper | 2.66:1 | `--cyan-ink` #177987, 4.64:1 |
| Everything downstream of those | — | passes |

The two invisible ones were real bugs, not shortfalls: text painted onto its
own colour. Both were on the homepage.

Three reported failures were **false positives** and were left alone: the SVG
diagram labels (the checker read CSS `color`, but SVG paints with `fill` —
they are 8:1), the card category captions (their backdrop is a gradient the
checker could not see — 4.7:1), and the search field's offscreen label, which
exists only for screen readers.

**Also fixed:**

- **Skip link added.** The masthead cost a keyboard user seven tab stops before
  any content, on every page.
- **Heading order.** 26 places skipped a level (`h2` → `h4`, `h2` → `h5`).
  Card and step headings are now `h3`; the footer's column headings became
  `h2` inside the footer landmark; the pipeline stage names became plain text,
  because they are diagram labels and never were headings.
- **Touch targets.** The breadcrumb and practice links were 18px tall; both are
  24px now. The remaining small targets are links inline in sentences, which
  the 24px rule exempts.

**Clean already:** every form control labelled, every image with alt text,
focus visible on all 55 tab stops of the homepage, one `h1` per page, `lang`,
`main`, and meta descriptions everywhere.

**Performance:** FCP 328–656ms locally, 7–9 requests, ~250KB uncompressed per
page — CloudFront will gzip that to roughly a fifth. The single third-party
render-blocking request is Google Fonts, which is item 4.

## 4. Self-hosted fonts and per-page share cards — one command on your machine

I could not finish these here: Google Fonts, gstatic, GitHub, npm and PyPI all
return 403 from my sandbox, so I cannot download a font file or the tooling to
subset one.

The mechanism is built and tested. Two scripts, and the build detects their
output and switches over by itself:

```bash
python3 tools/fetch-fonts.py     # downloads the woff2 files, writes fonts.css
python3 tools/make-og.py         # renders one share card per page
python3 build/make.py            # picks both up automatically
```

Until you run them, pages use the Google CDN and share the one og.jpg — so
nothing is broken in the meantime.

**Run the fonts one first.** The share cards are almost entirely type; rendered
without the real Newsreader and IBM Plex Mono, they go out in a substitute
face on every share. Worth knowing: the current `og.jpg` was made in this
sandbox and has exactly that flaw — `make-og.py` regenerates it correctly.

`make-og.py` needs Playwright (`pip install playwright && playwright install
chromium`). `fetch-fonts.py` needs nothing but Python.
