# build/ — what changed and why

Everything I built in `public/` is now generated by `build/`, so
`python3 build/make.py` reproduces it instead of wiping it.

## What was at risk

`wh.css` and `wh.js` are static — the generators only link to them, so all the
CSS and JS work was always safe. **The HTML and `assets/js/data.js` are
generated**, so every colour fix, copy cut and new graphic in those files would
have been destroyed on the next regeneration.

## Two bugs found while porting

- `services.py` keyed the new copy on practice ids `ai-ml`, `cloud`… but the real
  ids are `ai`, `cloud`, `salesforce`, `web`, `mobile`, `commerce`. Every card was
  silently falling back to the old lede with an empty situations list.
- `p['stack']` is a list of `(group, detail)` tuples, not strings — joining it
  raised `TypeError`. The card now renders the group names.

## Verified

`python3 make.py` runs clean and produces all 13 pages. Checked at 1440px and
390px: no horizontal overflow, no JS errors, no broken images, no retired brand
colours, no wireframe mark, no text lockup anywhere in the output.

Site body copy is now **5,293 words**, down from 5,698 — and the practice pages
come out *shorter* than the hand-edited versions, because the lede cuts now live
in `practices.py` where they belong.

## Still hand-edited (not yet in build/)

`assets/brand/*.svg` and `og.jpg` are static assets, correctly. Nothing else.

## Two traps worth remembering

Both cost real time this pass, and both produce *invisible* elements rather
than errors:

1. **IntersectionObserver will not reveal what it cannot see.** The reveal
   animation clips elements until they scroll into view — but the observer
   intersects a target *with its own clip*. A fully clipped element reports
   as never visible, so it never gets the class that would unclip it. Anything
   that starts at zero width has the same problem. Wipe a child, never the
   observed element.

2. **`.rv`'s `translateY(26px)` pushes the last child of a `.wipe` section
   past the parent's clip**, which lands you in trap 1. Keep the last child
   inside another element.
